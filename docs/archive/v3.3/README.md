# V3.3 campaign - phase 0

The journals, measurements and proofs of the phase that built the native
generation through phase 7: the Rust spikes, the shell rewrite, the OSD
measurements at three window sizes, the pointer work (decisions 124 to 127) and
the installer's terminal form. `REPRISE.md` is the hand-off note written at the
end of it, and `bilan-phase7.md` is the full account.

These are **evidence, not current documentation**. They record what was measured
on this machine on the dates in the files, including four faults that turned out
to be faults of the probes. The current product is described by
[`docs/v3.3.md`](../../v3.3.md), the [decision record](../../DECISIONS.md) and the
[design system](../../design-system.md).

`preuves/` holds the raw runs - console logs, JSON measurements, screenshots and
the CSV of surface fingerprints. Nothing here is a build input.
