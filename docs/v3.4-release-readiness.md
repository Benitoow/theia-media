## Limits

The Linux package contract is Ubuntu 24.04 X11/XWayland, software decoding and
SDR rendering, with PCM audio. Other distributions, hardware acceleration and
HDR output are not verified. Hosted Mac checks use the CPU rendering fallback;
physical Mac hardware decoding and HDR still need reports from actual devices.
These limits are stated in the release notes and do not become promises because
compilation or a playback counter passed.

No publication blocker remains within this contract. V3.4 is the last planned
V3 release; V4 plans and future optional supporter features follow decisions
159–162 and `docs/v4.md`. Core viewing/server/library remain free. This release stays GPL-3.0; from 4.0 the core is
source-available under PolyForm Noncommercial (decision 163).
