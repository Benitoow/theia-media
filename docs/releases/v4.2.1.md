# Theia 4.2.1 — sound beside your calls, fullscreen and complete updates

4.2.1 answers a tester's report on 4.2: a film no longer silences a voice call,
fullscreen from a maximized window covers the screen, the island no longer
repeats the control bar, the update button updates the player as well as the
server, and a server installed alone now updates itself. The server, library,
ordinary viewing and everything in this release remain free.

**Upgrading from 4.2.0 or earlier: run the new setup.** Your library, profiles,
friends and watch history stay in their data directory. The update button of
earlier players reaches the server alone; from 4.2.1 on, on Windows, it opens
the new setup for you.

On macOS and Linux, make the setup executable with `chmod +x` and its filename.
Mac apps are ad-hoc signed and not notarised; Windows binaries are unsigned.
Ubuntu still needs `libwebkit2gtk-4.1-0` and `libayatana-appindicator3-1`.

## Sound

- On Windows, a film no longer takes the audio output for itself. Before, every
  film opened the output in exclusive mode, and Discord or any other application
  went silent during it.
- If you send untouched Dolby or DTS to a home cinema amplifier, turn on
  **Settings → Playback → Untouched sound to the amplifier**. It is off by
  default because it brings exclusive mode back.

## Fullscreen

- On Windows, fullscreen from a maximized window now covers the whole screen.
  Before, the picture did not move and the taskbar stayed visible, so the
  fullscreen button seemed to do nothing.

## The island

- Alone, the island is a clock again: it says when the film ends and opens
  nothing. Its card repeated the title, timeline and buttons of the control bar
  beneath it.
- In a room, the control bar keeps its group button: it opens and folds the room
  in the island.
- An open room you are using keeps the controls up; left alone, it hides with
  them instead of staying over the film.
- A notice in an open room, such as the one after syncing your playback, shows
  its whole line and stays in sight when the room scrolls.

## Updating

- On Windows, **Settings → Server & updates → Update Theia** downloads the new
  setup, checks its published SHA-256 and opens it. The setup asks before it
  closes Theia and replaces every program. Where that is not available (macOS,
  Linux, or a player whose server runs on another computer), the button updates
  the server and says that the player is updated by the new setup.
- A server installed without the player now installs its updates by itself at
  start and every six hours, never during playback. A server with the player
  beside it still waits for you.

## Limits

- Passthrough to an amplifier was not re-measured with a receiver; behind the
  new switch it is the 4.2.0 path.
- The fullscreen correction was measured on a Windows machine whose taskbar
  hides itself; a fixed taskbar is the tester's case and was not available here.
- Rooms still need direct connectivity through the configured encrypted tunnel;
  Theia uses no third-party relay. Physical HDR output is not established.
