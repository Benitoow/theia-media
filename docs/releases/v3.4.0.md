# Theia 3.4 — wrapping up V3

3.4 is the last planned release of Theia V3. It feels good to finally write that.

The 3.3.1–3.3.6 releases were about getting the native generation into better
shape: fixing installation and updates, adding the `theia` launcher, bringing
the app to Apple Silicon, and giving playback, languages and subtitles their
own settings. There were plenty of rough edges along the way. 3.4 is the release
where I wanted to finish that work before moving on.

## Desktop downloads

Windows ARM64, Intel Macs and Linux join Windows x64 and Apple Silicon in this
release. Each download includes the installer, server, launcher and native
player with its media engine. Choose server-only, player-only or all-in-one
during installation.

Upgrading from 3.3? Run the new setup so the app and installer are replaced as
well. An automatic server update alone does not update the old desktop player.

On macOS and Linux, make the downloaded setup executable (`chmod +x` followed
by its filename), then run it. Mac apps are ad-hoc signed, not notarised, so
macOS may require you to allow the app in Privacy & Security on its first launch.

The Linux downloads were checked on Ubuntu 24.04, using X11/XWayland. Install
the platform packages first:

```sh
sudo apt install libmpv2 libwebkit2gtk-4.1-0 libayatana-appindicator3-1
```

Other distributions are not verified for these binaries. The Linux engine uses
Ubuntu's codec libraries. This first Linux release uses software decoding and
rendering in SDR; hardware acceleration and HDR output are not available yet.
Audio passthrough still needs verification on your own setup. The six separate
server files below are also kept for existing server updaters.

## A better place to pick a film

Films and series now have proper detail pages in the app: artwork, a synopsis,
TMDB information, cast portraits and the files available to play. The layout has
been reworked too: smoother backdrops, darker previews, a compact cast rail and
episode controls that sit where you need them.

You can inspect a file's resolution and HDR information before playing it. On
Windows, the app also checks the current display mode and the decoding profiles
advertised by the driver. Those checks describe what the device reports; they
cannot promise that every HDR or Dolby Vision file will play correctly on every
screen.

## Less friction between episodes

- Series now show where you stopped, on the home screen and on their own page.
- You can mark episodes as watched, reset their progress, or jump to the next
  unwatched episode. Near the end, the player offers the next episode directly;
  optional autoplay gives you ten seconds to cancel.
- Saved audio and subtitle preferences apply to episodes as well as films.
- The app remembers your server address, volume, mute state and window size.
  Changing or disconnecting from a server lives in Settings.
- A wrong or offline server address no longer holds the interface hostage.
  Connection attempts can be cancelled, and pending progress saves are retried.
- Keyboard help and a copyable playback diagnostic are easier to find. Large
  libraries and previews also do less work in the background.

The installer and launcher have had another round of fixes too, including
Windows application registration, removal and preservation of your library data.

## Where support goes from here

The desktop applications and the server remain actively maintained.

The web interface is staying available. If you watch on an iPhone, Android device
or TV, keep using your server's address in the browser for now. I consider the
web viewing interface complete, so it will no longer receive ongoing playback
or catalogue development and support. Server settings and administration will
continue to be maintained, as will the shared server APIs.

Dedicated mobile and TV apps will have to wait until the project has grown enough
to support them properly. There is no release date for those yet.

## Next: 4.0

There is no 3.4.1, 3.5 or 3.6 planned. The next release line is 4.0.

The direction is shared cinema: watch parties, a **Who's watching?** profile
chooser when the app opens, and a place to leave comments and like or dislike a
film. No direct messages or calls are planned. I want these features to help
people watch and talk about films together without turning Theia into another
messaging app.

These are the plans for 4.0, not features included in 3.4. I will share more as
the work takes shape.

## V4 will be free to try; optional social features will later support the project

I am aiming to finish V4 around late October or November 2026. That is an
estimate, not a deadline.

When those features arrive, enjoy them while they are free. Once work on V5
starts, I plan to make some of V4's optional shared-viewing and social features
paid supporter features. There will be no monthly subscription. Theia itself
will stay free and open source: your library, the server and watching your films
are not moving behind a paywall.

I see the social extras as an optional way to support the project. You do not
need them to watch a film properly. The transition will be announced before it
happens, with the exact features and payment terms explained then.

My current guess is late 2026 or early 2027. It could happen sooner if the
project moves much faster than expected, but none of these dates is fixed.
