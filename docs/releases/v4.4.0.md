# Theia 4.4.0 — a stable player, smaller updates

Theia 4.4 separates the native player from its interface. The window and media
engine stay installed; future compatible releases can update the interface and
server without downloading a new native player for every computer.

The server, library, ordinary viewing and all features in this release remain
free for noncommercial use. There is no cloud account or telemetry.

## Updating to 4.4

**Run the 4.4 setup once to replace the older player.** A server-only update
does not install the new interface loader. Your library, profiles, watchlists
and viewing history stay in place.

This is a native-player release. Future compatible product updates use signed
interface packs; an update that needs a new native capability still requires a
new player. A downloaded interface is verified before use, starts as a trial,
and falls back to the previous interface if it fails to confirm its launch.
An interface update does not interrupt a film and applies on the next launch.

## Reliability

- Playback keeps its original clock when a converted stream is reloaded.
- Progress writes retain the server and profile they belong to, remain ordered
  while offline, and preserve a newer position when an older write finishes.
- Leaving playback saves the latest position. Offline completion and resume
  indicators follow the same rules as the server.
- Existing local preferences and pending progress migrate to the stable
  interface origin. The original outbox is retained during migration.
- Autoplay follows preference changes made during playback and stays disabled
  in watch-party rooms. Borrowed room streams retain the selected profile.
- Artwork and original-language audio selection use the server's actual data
  shapes. Server requests have deadlines and can be cancelled.

## Downloads and platform limits

Use the setup for your platform from this release's assets. Each setup carries
the server, launcher, native player and media engine. Standalone server files
remain available for existing server updaters. Internal payloads and the shell
mirror are build inputs, not additional installation steps.

Platform availability follows the assets actually published with this release;
an unverified native build is not promoted. macOS apps are ad-hoc signed and
not notarised. Linux playback remains software-decoded SDR with PCM output.
Physical HDR/audio output and first-download Gatekeeper behaviour require
verification on the relevant hardware. Rooms need direct connectivity through
the configured encrypted tunnel; there is no third-party relay.
