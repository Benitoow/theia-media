# Theia 3.3.3: one picture everywhere, and rooms in the settings

If you use Windows x64, download this one file:

**[Download Theia 3.3.3 for Windows x64](https://github.com/Benitoow/theia-media/releases/download/v3.3.3/theia-setup-windows-amd64.exe)**

It installs the server, the native player, the `theia` command and the pinned
video engine, verifies every downloaded byte against GitHub's SHA-256 digest,
puts the installation on your `PATH` and registers it with Windows. If this
machine must install without a network connection, use the
**[complete offline bundle](https://github.com/Benitoow/theia-media/releases/download/v3.3.3/theia-3.3.3-windows-amd64.zip)**
instead, unpack it and run `theia-setup.exe`.

Everything else under *Assets* is a component consumed by the installer or the
automatic updater.

## What changed

- **The home's picture is the library's picture.** One recipe on every tab now:
  the featured film's backdrop is softened and melted into the page - away to the
  left, where the copy is, and away at the bottom - instead of sitting on the page
  as a rectangle. The hero's own scrims are gone with it, because the copy no
  longer sits over the picture at all. If the seam looked wrong, it was: the two
  halves of the product were drawing the same artwork in two different ways.
- **The settings sheet is a rail and a panel.** Interface, Playback, Server and
  Update down the left, the chosen section on the right. The language, the two
  playback preferences, the connected server and the update state each live
  behind their own heading instead of one long scroll. The sheet is wider than it
  was - the update row and its Check button used to hang out of the panel - and
  the footer is a bordered **Cancel** beside a filled **Save**.
- **The server address can be copied.** Behind Server, beside the address itself,
  with the confirmation in whichever language the application is speaking. The
  row ellipsises a long address; the button copies the whole one.

## Verification boundary

Everything below was run for this release, on Windows, from this tree.

- Go: `go vet ./...` clean and `go test ./...` green across every package.
- The native player: `cargo test` 11/11, `npm run check:i18n` (fr 140 / en 140),
  `npm run check:types` clean, and `npm run check:render` green - including the
  journey that walks all four settings sections, reads the copied server address
  back **from the clipboard** rather than trusting the sentence beside it, and
  measures each panel for sideways overflow.
- The real window: photographed on the home, the Films tab and the Series tab at
  1:1 (2,560 x 1,440), and on the settings sheet, before and after.
- The web application is untouched since 3.3.2 except for its version number;
  its verification - 43 unit tests, the three-viewport guard, the generated-media
  playback guard - is recorded in `docs/releases/v3.3.2.md`.

Not driven here: **Flow Launcher's own window and the Windows search box**, which
read exactly the Start Menu folder and the applications-list entry that decision
123 already verified.
