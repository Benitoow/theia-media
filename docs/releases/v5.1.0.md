# Theia 5.1 — Instant library refresh, system tray, Theia+ social beta and deep performance

**Real-time sync, dedicated headless control, and profound architectural speedups.**

Theia 5.1 builds directly upon the unified multi-source foundation of Theia 5.0. It brings instant library reconciliation via Server-Sent Events, a dedicated cross-platform system tray for headless servers, the opening of the **Theia+** social beta pass, an overhauled installer experience, and deep query and bundle optimizations cutting database round-trips by over 99%.

The core media server, high-fidelity native player (4K HDR, Dolby Vision, bitstream audio passthrough), remote access, and local library browsing remain **100% free and unencumbered**. There is no mandatory account, no cloud relay, and no telemetry.

This page records what was checked on which system, the measured benchmarks, and what remains unverified. Windows 11 is checked first.

## What arrives with 5.1

### 1. Instant Library Refresh (Real-Time Watcher & SSE)

In earlier versions, adding a movie or series required waiting for a 60-second polling cycle followed by a 15-second stability delay, or restarting the client application.

Theia 5.1 introduces an instant reconciliation pipeline:
- **Fast Watcher Tick:** Background polling interval cut to 10 seconds, with file stability debounce reduced to 3 seconds for fast copy settlement.
- **Server-Sent Events (SSE):** `GET /api/library/events` opens a persistent, low-overhead event stream pushing `library_changed` events as soon as local or Google Drive changes are reconciled.
- **Instant UI Invalidation:** Connected desktop players and web clients automatically invalidate their local catalog caches and refresh Home and Library views without requiring a page reload.
- **Immediate Rescan Triggers:** Manual rescan endpoint `POST /api/library/refresh`, system tray context action, and `F5` / `Ctrl+R` / `Cmd+R` keyboard shortcuts within the player.

### 2. Dedicated Headless Server Control (Cross-Platform System Tray)

When running Theia on a dedicated desktop tower, homelab server, or headless PC, running a visible player window is unnecessary and consumes GPU resources.

Theia 5.1 introduces a zero-CGO native system tray:
- **Windows Notification Area:** Direct Win32 Shell API integration (`Shell_NotifyIconW`, `TrackPopupMenu`) supporting light/dark theme notification icons, interactive desktop auto-attachment, and Explorer restart recovery (`TaskbarCreated`).
- **Context Menu Actions:**
  - Status header indicating server operational state and listening port.
  - *Open Web Admin* (`http://localhost:8383`).
  - *Rescan Library Now* (triggers immediate watcher cycle).
  - *Pairing Code & Devices* (opens server pairing settings).
  - *Stop Theia Server* (triggers clean SQLite flush and graceful shutdown).
- **macOS & Linux Integration:** Native startup and shutdown notifications via AppleScript (`osascript`) and desktop notification daemons (`notify-send`).
- **Remote Shutdown API:** Added `POST /api/server/shutdown` to gracefully shut down background servers from mobile or browser settings without terminal access.

### 3. Theia+ (Social Pass Beta)

Theia's core promise remains inviolable: **100% free, private media server and player without cloud dependencies, paywalls on viewing, or telemetry.**

To sustainably support social and multiplayer features:
- Optional social enhancements (friends list, online presence, synchronized watch party rooms, and community opinions) become **Theia+** (a one-time lifetime pass of 5.99 €).
- **Free Closed Beta:** For Theia 5.1, the Discord bot **Alex** in `#├・theia-plus` dispenses free beta passes (`THEIA-PLUS-XXXX-XXXX`) to field testers and community members.
- **Frosted Glass OSD Gate:** Accessing the Friends tab without entitlement renders an elegant frosted-glass blur overlay, explaining the pass and offering one-click Discord pass claiming or activation code redemption.

### 4. Pairing & Offline Server Resilience

- **6-Digit Server Pairing:** Fast pairing code generated in Web Admin settings simplifies connecting mobile phones and laptops without typing IP addresses.
- **Automated Windows Firewall Inbound Rule:** `theia-setup` automatically configures Windows Firewall rules for inbound TCP traffic on port 8383 for private networks during installation (`theia-setup --firewall`), eliminating silent connection rejections.
- **Connect Screen Troubleshooting:** The player connect screen now surfaces helpful diagnostic guidance when a saved server is sleeping, unreachable, or firewalled.

### 5. Deep Architectural Optimizations

- **N+1 SQLite Elimination:** `internal/catalogue/local.go` replaces per-movie and per-episode audio and stream quality queries with 3 batched queries (`batchAudioTracks` and `batchEpisodeNumbers`), slashing catalog compilation from 2,502 queries to 5.
- **SQLite WAL Pool & Memory Maps:** Connection pool expanded to 6 connections (`SetMaxOpenConns(6)`) for concurrent home-screen row loading. DSN augmented with `_pragma=mmap_size(268435456)` (256 MB) to eliminate kernel-to-user memory copies, `temp_store(MEMORY)`, and `PRAGMA optimize` on shutdown.
- **Frontend Bundle Decoupling:** `player/ui` decouples the 814.5 kB `SearchLoop` video loop asset via `React.lazy`, isolating it from the critical bundle path into an on-demand chunk.
- **React Memoization & O(1) Lookups:** `MediaCard.tsx` wrapped in `React.memo` with a custom equality comparator to eliminate re-renders on presence ticks; `Library.tsx` converts card lookups from an O(N) array search to an O(1) memoized map.

### 6. Installer Overhaul (Option A)

- **Preserved Lipgloss Aesthetic:** Retains 100% of the signature dark TUI design with custom gold borders.
- **Startup Latency Reduced:** Launch delay cut from 8s to 2s.
- **Paved Path Navigation:** Folder selection cursor defaults directly to `[Continue]`, allowing instant Enter-to-proceed installation.
- **Automated Shortcuts & Rules:** Automatically provisions Desktop shortcut and Windows Firewall inbound rules.

## Updating to Theia 5.1

- **From Theia 5.0:** Run `theia-setup` or check for updates in *Settings → Updates*. All library data, watch history, paired devices, and settings are preserved.
- **From Theia 4.x:** Run the 5.1 setup once to upgrade server binaries and native player configurations.
