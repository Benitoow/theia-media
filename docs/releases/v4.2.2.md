# Theia 4.2.2 — quality choices, and rooms without stray pauses

4.2.2 follows the field test of 4.2.1. The server, library, ordinary viewing and
everything in this release remain free.

## Downloads

Each setup contains the server, launcher, native player and media engine. Choose
all-in-one, server-only or player-only during installation.

**4.2.2 has setups for Windows x64 and Ubuntu x64 only.** The macOS and ARM
setups could not be built for this release; those platforms keep the 4.2.1
setup, linked below, and get these fixes with the next release. Servers
installed alone update themselves to 4.2.2 on every platform.

**Upgrading:** from 4.2.1 on Windows, **Settings → Server & updates → Update
Theia** opens this setup for you. From 4.2.0 or earlier, run it by hand. Your
library, profiles, friends and watch history stay in their data directory. A
server installed without the player updates itself.

On macOS and Linux, make the setup executable with `chmod +x` and its filename.
Mac apps are ad-hoc signed and not notarised; Windows binaries are unsigned.
Ubuntu still needs `libwebkit2gtk-4.1-0` and `libayatana-appindicator3-1`.

## Playback

- The quality menu offers its lower qualities for a film started without being
  inspected first. It used to say no other quality existed; the player now asks
  the server to measure the file the first time the menu opens, when FFmpeg is
  already installed.

## Rooms and the island

- In a room, a click on the film only shows the controls. It used to pause the
  film for everybody when somebody clicked beside a button.
- The room button in the control bar is gold while a room is on, so it says
  that a room is open as well as opening it.
- Alone, the island no longer draws a down arrow: it shows when the film ends
  and does not open.

## Limits

- A first opening of the quality menu on an unmeasured film can take a second
  or two while the file is measured.
- Sound reported as strange on one tester's machine since 4.2.1 is still being
  investigated. Where a home cinema amplifier or a headset handled the untouched
  stream better, **Settings → Playback → Untouched sound to the amplifier**
  brings back the 4.2.0 path (and its exclusive use of the audio output).
- Rooms still need direct connectivity through the configured encrypted tunnel;
  Theia uses no third-party relay. Physical HDR output is not established.
