# Theia V3.1 — un cinéma plus net

V3.1 resserre l'interface autour de ce que Theia fait le mieux : choisir un film
et le lancer, sans transformer la bibliothèque en site éditorial.

## Interface

- la navigation retrouve sa capsule de verre arrondie ;
- les trois raccourcis de l'accueil forment un dock compact, avec une nouvelle
  icône de lecture pour « Un film ce soir » ;
- la bibliothèque expose directement Ma liste, quatre durées et Choisir pour
  moi ;
- les cartes se soulèvent et révèlent une lecture circulaire sans cadre doré ;
- Rechercher devient une scène centrée avec une lumière de projection générée
  en CSS, puis rend les résultats dans la grille habituelle ;
- le téléphone conserve les mêmes actions, des cibles de 44 px et sa barre de
  navigation au pouce.

## Documentation

Le README a été reconstruit pour aller à l'essentiel : installation en trois
étapes, captures V3.1 prises sur le produit réel, configuration matérielle par
type d'usage, avertissement réseau et comparaison sourcée avec Plex, Jellyfin et
Emby.

## Compatibilité

V3.1 ne modifie ni la base de données, ni l'API, ni les contrats de lecture de
V3. Les versions Windows, macOS et Linux restent distribuées pour `amd64` et
`arm64`.

## Après V3.1 : test terrain

V3.1 devient la base fonctionnelle stable pendant que Theia cherche ses dix
premiers foyers testeurs. Les nouvelles fonctionnalités sont mises en pause :
les prochaines versions `v3.1.1`, `v3.1.2`, `v3.1.3`, etc. seront réservées aux
correctifs de sécurité, risques de perte de données, blocages de lecture,
régressions et problèmes concrets de compatibilité.

Les idées restent bienvenues et seront conservées. Le développement fonctionnel
reprendra quand les bibliothèques et écrans réellement utilisés auront produit
assez de retours pour décider du prochain cap. Le guide de test terrain et son
formulaire dédié sont disponibles dans le dépôt.

## Vérification

Le binaire final a passé les 75 contrôles de mise en page applicables sur
téléphone, ordinateur et télévision, les 7 scénarios de lecture réels, les 21
tests JavaScript, `go test ./...`, le contrôle des langues, les contrastes et la
construction du site. L'appel public au test terrain a été contrôlé visuellement
sur ordinateur et téléphone. La recherche a été rejouée avec une vraie réponse
sur les trois tailles, sans débordement. Le fichier Dune 4K a livré une image
décodée de 3840 × 1604 dans le binaire final. Les six cibles de distribution ont
également été recompilées localement avec `CGO_ENABLED=0`.
