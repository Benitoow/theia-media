# Theia 3.3.1: one door, fewer boxes

If you use Windows x64, download this one file:

**[Download Theia 3.3.1 for Windows x64](https://github.com/Benitoow/theia-media/releases/download/v3.3.1/theia-setup-windows-amd64.exe)**

It installs the server, the native player and the pinned video engine, verifies
every downloaded byte against GitHub's SHA-256 digest, and registers Theia in
Windows. If this machine must install without a network connection, use the
**[complete offline bundle](https://github.com/Benitoow/theia-media/releases/download/v3.3.1/theia-3.3.1-windows-amd64.zip)**
instead, unpack it and run `theia-setup.exe`.

Everything else under *Assets* is a component consumed by the installer or the
automatic updater. Its display label now says so. Linux, macOS and Windows ARM
keep receiving the headless server, but they do not get an installer presented
as a complete product until the native player has run on that hardware.

## What changed

- **The release is readable.** V3.3.0 exposed twenty equally weighted files.
  V3.3.1 publishes nine: the Windows installer and offline bundle first, then
  the seven explicitly labelled components the installer and updater require.
- **The V3.2 filename bridge is gone.** V3.3.0 carried six byte-identical server
  aliases so an existing V3.2 installation could cross the rename. They were a
  one-release bridge and have completed that job.
- **The player identifies its build.** `theia-player --diagnostics` now prints
  the tag compiled into the binary, and the release workflow refuses a player
  that does not report `v3.3.1`.
- **A resume-prompt race in the playback guard is fixed.** The browser suite now
  waits for the prompt before clicking *Start from beginning*, rather than
  occasionally waiting forever for a stream it never started.
- **The web dependency audit is clean.** `devalue` moves from 5.8.2 to 5.9.4,
  closing `GHSA-9rgm-9g3h-6x36`; `npm audit --audit-level=moderate` reports zero
  vulnerabilities.

## Verification boundary

Locally on Windows, the web build passed with zero Svelte warnings, all 43 unit
tests passed, the three-viewport browser guard passed 81 tests with its three
documented skips, and the generated-media playback guard passed 47 tests with
its five documented skips. Go tests and `go vet` passed, the native player's 10
Rust tests and real-browser render check passed, and all six server targets plus
the Windows x64 setup cross-compiled. A release bundle built with `v3.3.1`
loaded the pinned engine and reported its expected SHA-256 digest. The complete
offline archive reported `theia 3.3.1`, and a staging directory made from those
nine real artifacts passed the exact public-asset contract.
