# Theia 4.4.6

V4 maintenance release. Native-player update required.

- Remote access automatically reserves a different UDP port when the preferred
  one is occupied. Manual port conflicts now have a specific error.
- Automatic router forwarding is checked again while Theia runs, including
  rules without an expiry, so a lost mapping can be recreated. Failed changes
  preserve the previous listener and cleanup checks the rule's ownership.
- Server administration opens the system browser at the server settings page;
  browser-launch failure is visible and retryable.
- Player controls can hide again after returning to a maximized window, while
  keyboard navigation still keeps focused controls visible.

Run the 4.4.6 setup once, or use Theia's setup-update button. It replaces the
native player and keeps your library, profiles, watchlists and history. A
server-only update cannot deliver the administration fix. Existing compatible
interface packs remain supported by the new player.

No V5 features are included. Automatic recovery cannot make a network with
blocked incoming traffic reachable: Theia still uses direct WireGuard without
a relay. The real Freebox activation/recovery test passed; a connection between
two households has not been verified for this release.
