# Theia 4.4.1 — opinions between households, and who is around

The first fixes after 4.4.0 was tried by two households, and the first time
Theia's Firebase database carries more than introductions.

The server, library, ordinary viewing and all features in this release remain
free for noncommercial use. There is no cloud account or telemetry.

## Updating from 4.4.0

This is a **product release**: the native player does not change. Update from
Theia's own update button; the server is replaced, and the signed interface pack
that carries everything below is checked, kept, and applied the next time the
player starts. You do not need to run a setup again.

**Both of you need 4.4.1** to read each other's opinions through Firebase. With
a friend still on 4.4.0, presence keeps working and an *inactive* friend simply
reads as online; their opinions are still asked through the encrypted tunnel,
which needs direct connectivity between your two servers, as before.

## What changes

- **One opinion per title, and you see it.** Once you publish words about a film
  or a series, they appear as your own review - with your thumb, the date, a
  spoiler mark if you set one - with **Edit** and **Delete**. The box that wrote
  them comes back only to change them. Publishing again replaces your opinion;
  it never adds a second one.
- **Your friends' opinions reach you without an open port.** Opinions now travel
  through Theia's Firebase database, like friend requests and presence, so two
  households whose routers do not let each other in can still read what the
  other thinks. A page you keep open looks again every twenty seconds.
- **Online, inactive, offline.** A friend whose player nobody has touched for
  five minutes is shown as *Inactive*; a friend whose server is off is *Offline*;
  someone playing a film is *Watching*. Each picture carries a filled dot, a ring
  or a dimmed face. A friend shown as inactive is not counted among the friends
  online in the library bar. The player tells its own server that somebody is
  there at most every thirty seconds, while its window is visible; nothing is
  stored.

## What Firebase now holds

Theia's Firebase database still receives directory entries for all local
profiles, including names and pictures, and exchanges requests and presence
between linked friends under anonymous server identities. **New in 4.4.1:** the
thumb and the text of each opinion you write are stored there, in the inbox of
each friend who can read it, until you delete the opinion, end the friendship, or
that friend deletes it. Only that friend's server can read its inbox, and only
your server writes under your profile. Presence gains one flag, *inactive*. Your
library catalogue and viewing history are still not sent, and no sign-up is
required.

## Downloads

4.4.1 publishes the six standalone servers, the setups for **Windows x64, Linux
x64, macOS Apple Silicon and macOS Intel**, and the signed interface pack with
its signature. Windows ARM64 and Linux ARM64 keep the 4.2.1 setups the website
links, until their native checks can run. A setup of this release carries the
native player verified for 4.4.0.
