# Theia 5.1.1 — Official Electric Flame branding, pure OLED black and refined social layout

**Theia aligns with its official flame identity, delivers true pixel-off OLED contrast, updates Windows application icons, and refines the Theia+ social interface.**

Theia 5.1.1 is a focused Product Release following the performance and real-time synchronization milestone of Theia 5.1. It delivers the complete visual harmonization of Theia with its official brand mark, transitions the design system to pure OLED black, embeds multi-resolution official icons into Windows binaries, and resolves layout spacing in the Theia+ social friends dialog.

In accordance with Decision 196, this is a **Product Release**: the native player engine (Rust/libmpv) remains frozen, with updates delivered via the signed interface pack (`theia-ui-5.1.1.zip`), updated pure-Go server binaries, and installers.

---

## What arrives with 5.1.1

### 1. Electric Flame & Pure OLED Black Design System (Decision 239)

Theia's visual identity now directly embodies the radiant energy of its official flame mark (`assets/theia-icon.png`):

- **Electric Flame Palette:** Superseding the legacy amber/gold palette, Theia adopts vibrant Electric Flame red-orange (`#FF4500`), paired with warm neon flame amber highlight (`#FFA100`) and deep crimson ember (`#8B1E00`).
- **Pure OLED Black (`#000000`):** Surfaces across the web client, native player OSD sheets (Settings, Friends, Profile, Audio/Subtitle menus), connect screen, glyph swells, loading screen, public website, and installer TUI now use pure `#000000` (`--color-ink`). This delivers true pixel-off contrast on OLED televisions and displays, eliminating back-panel glow in dark viewing rooms.
- **Audited Contrast Ratios:** All tokens have been audited and verified via `scripts/contrast.mjs` against WCAG AA requirements on pure black:
  - `--bone` (`#F4F4F6`): **19.12:1** (primary text & titles)
  - `--parchment` (`#DCDCE2`): **15.38:1** (secondary text & synopsis)
  - `--muted` (`#8E8E98`): **6.47:1** (metadata & labels)
  - `--accent` (`#FF4500`): **6.10:1** (brand accent & interactive rings)
  - `--accent-bright` (`#FFA100`): **10.35:1** (focus & hover highlights)

### 2. Refined Friends Dialog & Social Presence Layout

Following community feedback on the Theia+ closed beta, the Friends dialog layout has been overhauled to resolve visual alignment and spacing defects:

- **Section Hierarchy & Void Elimination:** Resolved grid container constraints in `osd.css` (`.friends-content-container`), eliminating unintended stretching and the empty vertical void between section headers and friend status groups.
- **Divider Isolation for Friend Codes:** The Friend Code and Add Friend sections now sit below dedicated hairline dividers (`border-top: 1px solid var(--color-line)`) with proper padding, preventing the user's friend code from appearing glued against friend presence cards.
- **Flexible Scrolling:** The unlocked dialog flows naturally with content-adaptive vertical rhythm, while preserving the frosted glass blur and Discord beta gate when unlocked pass entitlement is not present.
- **Crisp Presence Headers:** Status groupings ("En ligne", "Hors ligne") feature refined uppercase typography with muted contrast.

### 3. Windows Application & System Tray Icons

- **Multi-Resolution Windows Icons:** Generated a comprehensive icon ladder (16×16, 24×24, 32×32, 48×48, 64×64, 128×128, 256×256) directly from the vector master of the official flame logo.
- **Compiled Syso Resources:** Recompiled Windows resource objects for all architectures (`cmd/theia-server/`, `cmd/theia-setup/`, and `cmd/theia/` for `amd64` and `arm64`) using the `rsrc` tool. File properties, taskbar pins, and desktop shortcuts on Windows now display the crisp official mark.
- **System Tray Icon:** Updated `internal/tray/icon.ico` and player icons (`player/theia-player/icons/icon.ico`, `icon.png`) with the official mark.

### 4. Verification & Scope

- **Zero Native Shell Code Changes:** The native Tauri/Rust/libmpv player shell remains untouched and binary-compatible per Decision 196.
- **Pure Go (`CGO_ENABLED=0`):** All Go servers and installers maintain zero CGO dependencies.
- **100% Passing Test Suites:** Validated via Go unit tests, frontend builds, contrast audits, and visual browser verification under Playwright.
