# Theia 4.3.0 — between friends, and the Macs are back

4.3 lets friends tell each other what they thought of a film, redraws the
title pages, makes the player lighter and faster, and brings macOS back. The
server, library, ordinary viewing and everything in this release remain free.

## Downloads

Each setup contains the server, launcher, native player and media engine. Choose
all-in-one, server-only or player-only during installation. **From 4.3 the setup
looks for a newer setup before it installs**: a file you kept, or sent to a
friend, installs the newest Theia, and works offline with what it carries.

**macOS is supported again**, Apple Silicon and Intel. **The ARM64 setups
(Windows and Ubuntu) follow in early November**, once their machines can run
the native checks; until then those computers keep the 4.2.1 setup. Servers
installed alone update themselves to 4.3.0 on all six platforms.

**Upgrading:**

- **Windows 4.2.1:** **Settings → Server & updates → Update Theia** opens this
  setup for you.
- **macOS and Linux 4.2.1:** run this setup once. The 4.2.1 player's button
  updates the server alone; from 4.3 on, it updates everything: the player
  closes, every program is replaced, and Theia opens again on its own.
- From 4.2.0 or earlier, run the setup by hand.

Your library, profiles, friends and watch history stay in their data directory.
An older setup never replaces a newer installation.

On macOS and Linux, make the setup executable with `chmod +x` and its filename.
Mac apps are ad-hoc signed and not notarised: the first time, open the app with
Control-click → Open. Windows binaries are unsigned. Ubuntu still needs
`libwebkit2gtk-4.1-0` and `libayatana-appindicator3-1`.

## Between friends

- On a film or a series, a thumb up or down and a short review of up to 500
  characters, with a spoiler switch that blurs it for the others.
- Your friends' opinions appear on the same page, with their profile photos.
  Only friends who added each other see them, and each opinion stays on its
  author's server: nothing is copied anywhere else.

## Title pages

- A header that plays the title, with the poster beside it, then tabs:
  episodes, synopsis, cast, saga and reviews.
- **Playback on this device** concludes: opening it measures the file (fetching
  FFmpeg first when the server does not have it yet), and each line says
  whether it works, works with a conversion or is at risk, and why. It reports
  what the driver and the screen announce, never a promise the playback alone
  can keep.
- A cleaner version chooser for titles with several files.

## Lighter and faster

Measured on the same machine before and after: the player is 11.5 MB instead of
15.1 MB, its interface 1.7 MB instead of 4.5 MB, a title page opens in 242 ms
instead of 361 ms (worst case 253 ms instead of 877 ms), and the search page
uses half the processor it did.

## Updates

- An update offers the newest release that has a file for your computer, so a
  platform left out of a release no longer reads "update available" followed by
  "no binary for this system".
- On macOS and Linux an update closes the programs it replaces instead of
  leaving the old ones running, and a server kept by launchd or systemd is
  restarted by it.

## Also

- **Who is watching** draws each profile's ring in the colour of its photo.
- Errors and warnings in the player are tinted again: their colours were never
  declared, so they had been drawn plain.

## Limits

- The ARM64 setups are not in this release yet (see above).
- Gatekeeper on a first downloaded launch, and Mac hardware decoding and HDR,
  are not established; the Mac checks run on machines that render in software.
- Rooms still need direct connectivity through the configured encrypted tunnel;
  Theia uses no third-party relay. Physical HDR output is not established.
