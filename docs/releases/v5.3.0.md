# Theia 5.3 — new original brand imagery, Obsidian OLED palette, bidirectional pairing and sync, and hybrid series

**All brand logos and icons have been redrawn from scratch on rights-cleared masters (`assets/README.md`), surfaces move to neutral Obsidian OLED (`#141414`), pairing two servers now connects both directions in one step and keeps profiles and watch progress synchronized, local and remote seasons merge seamlessly on the title page, and server settings split into three clearer tabs.**

Theia 5.3 (`v5.3.0`) is a **Shell Release** (decisions 196 and 247): the native `theia-player` shells on Windows, Linux, and macOS (Apple Silicon and Intel via Codemagic), all six `theia-server` binaries, all installers/archives, and the Android application (`theia-android-5.3.0.apk`) are rebuilt so no legacy copyrighted icon remains embedded in any shipped executable or bundle.

---

## What arrives with 5.3

### 1. Rights-cleared brand artwork across every target (decision 247)

- Four clean lossless master PNGs live in `assets/` (`theia-icon.png`, `theia-icon-no-text.png`, `theia-logo.png`, `theia-logo-no-text.png`), with every derived asset and generator documented in [`assets/README.md`](../../assets/README.md).
- Every shipped icon and graphic target has been regenerated from those masters: desktop player icons (`icon.png`, `icon.ico`), system tray (`internal/tray/icon.ico`), all six Windows PE resource `.syso` objects (`cmd/theia`, `cmd/theia-server`, `cmd/theia-setup`), setup TUI boot emblem, web viewer & public site favicons (`favicon-16.png`, `favicon-32.png`, `apple-touch-icon.png`), Android adaptive background + Leanback TV banner (`banner.png`), and Play Store listing assets updated to 5.3 with Electric Flame & Obsidian OLED colours.

### 2. Obsidian OLED surface palette (decision 246)

Neutral grey surfaces drop from `#333333` / `#404040` / `#4D4D4D` to deeper Obsidian OLED tones (`#141414` panels, `#1E1E1E` raised surface/hover, `#2B2B2B` hairlines) across the web interface, player OSD, installer palette, fallback HTML, and public site—preserving neutral tone on OLED displays while giving body copy (`Muted` `#C0C0C0` 11.54:1 vs `#000000`) and Electric Flame UI accents (`#FF4500`, 5.35:1 on panels) comfortable contrast headroom.

### 3. Bidirectional pairing and automatic profile/progress sync (decision 245)

- Redeeming a pairing code over HTTP with a reachable local address now includes a reciprocal peer offer (`origin`, `base_url`, bearer grant, capabilities, and host facts), so both servers register each other in one action instead of leaving a one-way link.
- Pairing, reconnection, and background profile/progress writes exchange `/api/ecosystem/v1/sync` bundles carrying viewer identities, profile names, avatars, Theia+ activation, and canonical watch progress (`viewer_progress`, mirrored to local movie and episode progress rows where media exists locally).

### 4. Hybrid local and remote seasons on the title page (decision 245)

When one server holds part of a series locally (for instance Season 1 on a laptop) and a paired server holds additional seasons or copies, `mergeSeriesCards` and `mergeMovieCards` keep peer copies alongside local metadata and `LocalTitlePage` merges missing remote seasons and episodes right into the episode view, routing playback and watched state to whichever server owns the file.

### 5. Focused three-tab server settings & polish (decision 245)

- The old stacked server settings view splits into **Library & sources**, **Access & devices**, and **Server & maintenance**, with tighter mobile navigation spacing (`settings.css`) and removal of duplicate active-interface status rows in **Updates** (`SettingsModal.tsx`).
- Drive background indexing (`internal/drive/index.go`) fixes a context cancellation race.

## Updating

- **The desktop player & server (Windows, macOS, Linux):** install from `theia-setup-*` (or extract the macOS / Linux archive), because 5.3.0 refreshes the native shell bundles as well as the servers and interface pack.
- **Standalone server:** `theia-server-*` binaries are rebuilt for all six targets.
- **Android:** install `theia-android-5.3.0.apk` (version code `50300`), signed with the same release key as V5 so it upgrades in place.
