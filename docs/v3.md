# Theia V3 — a dependable private cinema

V3 turns the September 2026 audit into a release, with an editorial cinema
interface and a playback pipeline that can be tested end to end. The maintainer
authorised implementation, design changes and the V3 release on 5 September.

## Release scope

- [x] LAN Host/Origin protection and explicit remote route policy.
- [x] Browser-managed fragmented MP4 transport, cancellation, bounded buffering,
  consistent seek clocks, actionable errors and film/episode parity.
- [x] Atomic playback/update admission, playback heartbeats and retained rollback.
- [x] Honest settings activation and file stability during automatic scans.
- [x] Refined navigation, home, discovery and detail screens; useful library
  filtering; accessible player with a 44 px minimum hit area.
- [x] Populated, playable browser fixtures; static Svelte checks; release gates.
- [ ] Real Dune playback, seeks, audio and subtitles on disposable data; cross
  builds; site, documentation, V3 release and CI verification.

## Product decisions

Keep the private, single-binary installation, FFmpeg as the only external runtime,
French/English and no telemetry. V3 may replace old visual/transport decisions
where measurements justify it. The UI should feel like a programme of films:
warm black, parchment, restrained brass, strong serif titles, clear navigation,
artwork when present and intentional typographic placeholders when absent.

Playback is a transport contract, not a boolean called remux. File-backed direct
play retains HTTP Range. Fragmented output is fetched into MediaSource on capable
browsers, so native byte-range retries cannot start a second HDR conversion.
Buffers are bounded; changing position cancels the old session. Native fallback
must remain honest about browser support. Real media decides release readiness.

## Verification record

Verified locally on Windows, Chromium 151, Node 24 and Go 1.26.5:

- `go test ./...` and `go vet ./...` passed. Targeted regressions cover playback
  admission, an update raced by playback during download, fresh/replaced files,
  watchlist profile isolation and cascading deletion, legacy stream links,
  settings activation, cached artwork and LAN/remote route boundaries.
- Svelte JavaScript checking is enabled: zero errors, zero warnings. It found an
  obsolete audio variable in the film inspection callback. Locale parity,
  backdrop validation and documented contrast ratios pass. npm audit: zero.
- 21 JavaScript unit tests and 7 populated playback tests passed. The latter
  generate H.264/AAC, H.264/AC3, MPEG-2/AC3 and an episode locally, and cover
  decoded frames, seek clocks, pause, watchlist persistence, duration filtering,
  audio selection, visible text subtitles and recovery from startup failure.
- 75 layout checks passed on a fresh installation (3 inapplicable shared-edge
  checks skipped); 78 layout checks passed on the disposable 256-film catalogue at 375, 1280 and
  1920 pixels, including the profile page. The initial run caught a 27px profile
  brand link; it is now a 44px target. Desktop and phone captures were inspected.
- All six windows/linux/darwin x amd64/arm64 cross builds passed with CGO off.
- Public site builds in French and English and passes its structural checks.
- Dune's real HEVC 10-bit HDR/Dolby Vision, TrueHD/Atmos file played for about
  95 continuous seconds in a 100-second observation after startup, at 3840px
  width. Audio decode bytes increased from 37 KB to 2.26 MB; the buffer settled
  near 25 seconds. A nearby seek reused the buffer. A distant seek requested
  t=3600 and the clock reached 3604; the 1080-height selection produced
  2586x1080 with continuing audio/video. Transient encoder-busy responses during
  replacement were retried successfully. No runtime exception was observed.

Dune was read from the real media file with a disposable database/cache copy;
synthetic fixtures and copies are in `%TEMP%/theia-v3-validation`. Personal
configuration and history were not edited; port 8383 was not used. Dune artwork
paths were restored in the disposable database from a read-only original query
so the final visual check used the already cached images.

Limits: native Safari/Firefox, physical TV/remotes and subjective A/V sync were
not measured in this run. The Dune observation is not a full-film test. No Go
race claim is made: the project runs with CGO disabled. Publication and remote
CI results will be recorded after the release workflow finishes.
